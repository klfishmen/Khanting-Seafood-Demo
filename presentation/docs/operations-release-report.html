盤點與依據

  • 正式私有專案於本次 Demo 開發中僅供唯讀參考。
  • 獨立 Demo 前一版 987da2c38bf25abf4ca63490c149baa369440b76。沿用目前的商品庫存、公告影片、模擬信件、付款回填與核帳、整單分配及重設。
  • 唯讀參考正式出貨決策、資料模型 V1.2 與營運週期規則。首次正式分配鎖定收件，未核對、退款異常及重複分配均阻擋，取消與退款不自動回補庫存。

實作與相容性

  • src/admin.html、src/admin.js、src/admin-operations.js、src/styles.css 提供九區導覽、共用篩選、訂單詳細及鎖定、批次例外、A4 列印、損益、會計更正及 CSV。
  • src/operations.js 集中台北時間與週期、批次條件、核帳衍生現金、成本快照計算與 CSV 序列化。聚合和明細以同一份資料計算。
  • src/demo-state.js、src/demo.js、src/index.html、src/rules.js 保留原狀態鍵，新增舊單相容欄位及收件選擇。舊成本不回填現在商品資料，有證據才帶入舊日期，原有訂單及購物車保留。
  • 付款、收件人及出貨資料以合成情境展示。對外發布限 scripts/public-files.mjs 的靜態白名單。文件與測試保留在本機。
  • 本機維護測試、發布白名單、操作手冊及報告。

測試與安全

  • 最終建置產生 40 個靜態檔案。單元測試 9/9，包含週二正午、核帳來源、退款上限、成本快照、缺資料、批次守衛、舊資料遷移及 CSV。
  • 靜態白名單、機密及外部服務掃描、PPTX 套件掃描通過。正式專案的既有檔案保留。
  • 本機 Chrome 1440、820、375px 確認下單、人工核帳、退款阻擋、單一批次、收件鎖定、取消保留庫存、A4 揀貨、商品成本快照、淨利、帳務更正與 CSV，以及既有前台、後台、歷程、簡報和重設。
