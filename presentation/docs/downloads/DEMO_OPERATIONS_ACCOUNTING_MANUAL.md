# 營運管理中心 V1.0 操作手冊

適用於 [獨立 Demo 後台](https://klfishmen.github.io/Khanting-Seafood-Demo/admin.html)。請使用同一個瀏覽器及同一個網站來源開啟前台與後台。資料存入該瀏覽器的 localStorage。所有商品、收件人、匯款與出貨均為模擬，請只填虛構資料。

## 1. 建立訂單並人工核帳

1. 前台將現流透抽兩份加入購物車。使用示範 Email `demo-buyer@example.invalid` 及後四碼 `1234`，送出訂單。開賣且未達免運的情境下，商品 NT$520、運費 NT$130，合計 NT$650。
2. 至「訂單管理」搜尋訂單編號，或使用顧客名稱、遮罩手機、日期、週期和狀態篩選。「查看詳情」可看到商品小計、整單運費、售價及成本快照、收件與狀態歷史。
3. 開啟模擬信件或訂單中的回報表單，填應付金額與合成末五碼 `54321`。提交後是待核對。
4. 到「付款核帳」人工核對。金額或末碼不符時仍未付款，顧客可重新回報。核帳成功才在流水帳出現該訂單的一筆收款。
5. 未付款且未分配的訂單可在詳情輸入原因後取消。取消不調整庫存或週累積。退款異常會阻擋未完成的出貨，實際退款由展示帳務分開記錄。

## 2. 整單出貨與列印

1. 正式分配前，收件人可在回填頁變更虛構門市組合，後台也可在訂單詳情編輯姓名、手機及兩間門市。門市代碼選填。
2. 到「出貨單管理」建立批次，再回「訂單管理」按「分配所選批次」。逐筆分配可把多張合資格訂單放入同一批。未付款、退款異常、已取消、缺收件資料及已分配的訂單會被阻擋。分配時鎖定收件快照。
3. 以批次編號、備註或狀態篩選。批次列顯示建立日期、訂單量與商品總件數。按「出貨單」或「揀貨清單」可預覽並用瀏覽器列印 A4 或另存 PDF。出貨單顯示手機遮罩與門市，揀貨清單合計同商品數量。
4. 依序推進待揀貨、已揀貨、待寄件、已寄件、已完成。「已寄件」會一起標記尚未模擬出貨的批次訂單。舊有單筆「標記模擬出貨」也保留，適用同一出貨安全檢查並留紀錄。
5. 批次異常需填原因，會擋住列印及下一步。解除也需留下原因。若其中一張訂單仍有退款異常，解除批次標記後仍會阻擋。

## 3. 損益分析 · DEMO PROPOSED

- 「總覽與訂單篩選」以台北日期及 `weekly_cycle_id` 選擇訂單群組。週期代號以週二中午起點日期表示，例如 `W-2026-11-17`。展示情境可切換接單畫面，日期和週期仍以建立訂單的實際台北時間記錄。
- 訂單銷售總額含運費並排除取消單。已核帳收款含已核對的商品與運費，未核帳銷售另列。商品成本使用訂單成立當時的快照，商品後續改價或改成本不會回寫舊單。
- 淨利＝商品毛利＋顧客支付運費＋其他收入－物流費－其他營運費用－已記錄退款－調整支出。進貨付款看流水帳，損益以商品成本計入，避免重複扣除。選商品或分類時只看商品層級，整單費用不分攤。
- 例：兩份透抽的商品成本共 NT$300、毛利 NT$220。核帳 NT$650、實付物流 NT$120，無其他帳務時，示範淨利 NT$230。缺商品成本或物流資料時，受影響指標會顯示待補；物流確定免費時可登記 NT$0 並說明。
- 明細、銷售趨勢、商品毛利排行及週期摘要用同一份模擬資料。週期或單筆訂單報表只帶入連結該批訂單的帳務，未連結費用按帳務日期留在全站期間報表。

## 4. 會計流水帳 · DEMO PROPOSED

1. 登記其他收入、進貨、物流、包材、平台或手續費、其他費用、退款或調整支出。輸入日期、整數金額及備註，物流或退款須連結已核帳訂單。退款前須在訂單標記異常，累計金額不得超過原收款。
2. 已核帳收款由訂單即時計算，不能透過手動帳務再登記。「其他收入」限未連結訂單的非訂單收入。
3. 在「更正」修改同一筆帳務並說明原因。現金及損益採目前版，使用「更正歷史」檢視前後版本。現金按收付款日期及目前篩選條件加總。
4. 「匯出 CSV」輸出篩選結果，以 UTF-8 BOM 支援 Excel。可用「列印現金報表」或「列印損益報表」匯出紙本及 PDF。

## 常見問題、重設與正式差異

- 前後台資料不同步時，先確認同一瀏覽器設定檔和網站來源。隱私模式或其他裝置會各有一份資料。
- 舊單若缺成立日、核帳日或成本，顯示待補。有可追溯操作時間時才帶入舊單及舊批次科目。
- 「重設展示資料」會一起清除本瀏覽器的訂單、購物車、批次、帳務及操作紀錄，並恢復預設商品與成本。
- Demo 使用頁面操作及瀏覽器資料模擬庫存；正式規格要求成功下單由後端交易扣庫存。正式環境還需要授權、交易一致性、稽核、收件隱私及真實物流的獨立驗收。
- 本資料是 Demo 管理報表，非正式財務報表或稅務申報系統。正式實裝待確認收入與成本認列、物流及共同費用分攤、跨期退款、收件解鎖、異常處置、調整授權及對帳憑證。
